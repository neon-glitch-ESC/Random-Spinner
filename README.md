# 🎡 Random Spinner

A simple and interactive random spinner web app built using HTML, CSS, and JavaScript.

## ✨ Features

- Random spinning wheel
- Smooth animations
- Responsive UI
- Lightweight and fast
- Easy to customize

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript
